## About

I'm a final-year B.Tech Computer Science student, currently looking for full-stack and AI developer roles. This site is where I showcase what I've built — from AI-powered web apps to IoT health monitoring systems — along with my technical background and scholarship history.

## Features

- Smooth scroll-triggered animations powered by Motion (Framer Motion)
- Sections for About, Technologies, Scholarships, Projects, and Contact
- Fully responsive layout built with Tailwind CSS
- Social links (LinkedIn, GitHub, Instagram) in the navbar

## Tech Stack

**Frontend:** React 19, Vite, Tailwind CSS 4, Motion, React Icons

**Tooling:** ESLint, PostCSS, Autoprefixer

**Deployment:** Vercel

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/omkarg04/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The site will be available at `http://localhost:5173`.

### Build for production

```bash
npm run build
```

### Lint

```bash
npm run lint
```
